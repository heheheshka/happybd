DREAMLAND — сайт-приглашение

Открыть index.html в браузере. Для публикации на GitHub Pages загрузить все
файлы из архива в корень репозитория (index.html, style.css, script.js,
config.js и папку assets). Settings → Pages → Deploy from a branch → main / root → Save.

Дизайн: оригинальные фоны Desktop 1280×1080 и Mobile 375×1080; текст в HTML,
шрифты Great Vibes и Geologica Light подключены через Google Fonts (для их
загрузки нужен интернет). При недоступности Google Fonts используются
резервные системные шрифты. Основная кнопка воссоздана в CSS.

Ссылки и пожелания редактируются в config.js. Парк Победы и оба вишлиста
уже подключены. Пожелания перемешиваются без повторов в рамках одной загрузки
страницы, пока не исчерпается список. Подтверждение участия только локальное:
оно не отправляет данные организаторам и не собирает персональные данные.

ЗАМЕНА ПЕРСОНАЖЕЙ
assets/character-olya.png — Оля (справа)
assets/character-liza.png — Лиза (слева)
Заменить PNG, сохранив имя файла и по возможности размер прозрачного холста
(694×782 и 694×789 соответственно), положение и пропорции фигуры внутри.
Если пропорции сильно изменятся, поправить .character-olya или .character-liza
в style.css (отдельно для мобильного и десктопа).

ПОП-АП
Оригинальные PNG из Figma уже подключены: assets/popup-art.png (707×476)
и assets/popup-art-mobile.png (308×473). Версия выбирается автоматически.
Текст заголовка и пожелания остается живым HTML. Размер пожелания подстраивается
под плашку. Закрытие — крестик, нажатие за пределами окна или Escape.

СЕРЕБРЯНЫЙ ЗАНАВЕС
При открытии страницы дождик закрывает экран, затем через 1,05 секунды
эффектно разъезжается (2,1 секунды) с мягким сиянием и звездочками. На десктопе остается только в свободных
боковых областях, на мобильном исчезает полностью. Системная настройка
уменьшения движения отключает анимацию. Изображения: assets/curtain-left.png
и assets/curtain-right.png. Изображения взяты из новых оригиналов 1920×1080 без увеличения:
удалены только прозрачные поля. Настройки анимации: style.css и script.js.
